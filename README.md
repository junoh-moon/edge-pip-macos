# Edge PiP for macOS

Microsoft Edge에서 기본 화면 속 화면(PiP) 버튼을 누르면 다른 데스크톱이나 전체 화면 앱으로 옮겨도 영상을 이어 볼 수 있습니다. 보조 앱은 Edge가 재생 중인 PiP 창을 표시합니다. 영상 주소를 새 플레이어에서 다시 열지 않습니다.

## 사용 방식

- 일반 영상에서 Edge의 기본 PiP 버튼을 누르면 모든 데스크톱과 전체 화면 앱에 같은 보조 창이 나타납니다. Edge의 원래 창은 화면 밖에서 영상 프레임을 공급합니다. 보조 창 크기를 바꾸면 원래 창 크기도 따라갑니다.
- 포인터를 올리면 크기 조절, 닫기, 원래 탭으로 돌아가기가 가능합니다. 함께 제공되는 Edge 확장을 사용하면 재생, 탐색, 음량 및 사이트가 지원하는 이전·다음 영상도 조절할 수 있습니다.
- 티빙 등 보호 영상이 재생되는 동안에는 보조 앱이 화면 캡처를 멈춥니다. 보호 영상의 기본 PiP 버튼은 Edge 원래 창을 표시합니다. 마지막 보호 영상의 재생을 끝내면 일반 영상의 PiP 표시가 재개됩니다. 영상이나 소리를 파일에 저장하지 않습니다.

## 빌드와 설치

macOS 15 이상, Microsoft Edge, Xcode 명령줄 도구와 Python 3가 필요합니다. 저장소 루트에서 실행하십시오.

```sh
./scripts/build.sh
```

1. 생성된 `build/Edge PiP.app`을 사용할 위치로 옮기십시오. 예를 들어 응용 프로그램 폴더에 두면 경로는 `/Applications/Edge PiP.app`입니다.
2. 아래 명령으로 Edge에 로컬 연결을 등록하십시오. 앱을 다른 위치에 두었다면 경로를 맞추십시오.

   ```sh
   python3 scripts/register-host.py "/Applications/Edge PiP.app/Contents/MacOS/EdgePiPRelay"
   ```
3. Edge에서 `edge://extensions`를 열고 개발자 모드를 켜십시오. ‘압축 풀린 확장 로드’에서 이 저장소의 `extension` 폴더를 선택하십시오.
4. Edge PiP 앱을 실행하고 macOS에서 화면 기록과 손쉬운 사용을 허용하십시오. 손쉬운 사용은 Edge의 PiP 창을 화면 밖으로 옮기고 복구할 때 사용합니다. 이후에는 Edge의 기본 PiP 버튼으로 사용할 수 있습니다.

기본 빌드는 임시 서명을 사용합니다. 빌드 사이에 권한을 유지하려면 키체인에 있는 동일한 코드 서명 인증서의 SHA-1 지문을 `EDGE_PIP_SIGNING_SHA1` 환경 변수에 설정한 뒤 빌드하십시오.

## 해상도 테스트

빌드한 뒤 다음 명령으로 테스트를 실행하십시오. 테스트 창을 확대하고 축소하면서 보조 창에 전달되는 프레임의 실제 픽셀 수와 축소 배율을 검사합니다.

```sh
xcrun swiftc -D CAPTURE_RESOLUTION_TEST Sources/*.swift Tests/CaptureResolution.swift -o build/test-resolution
./build/test-resolution
```

## 작업 이력

- **1.5** — 일반 영상은 모든 공간에서 보조 창 하나로 표시하고, 보호 영상은 Edge 기본 PiP로 자동 전환합니다. 보조 앱이 종료되면 원래 창이 화면 안으로 돌아옵니다.
- **1.4.1** — Edge 원래 PiP 창을 키우거나 배율이 다른 모니터로 옮길 때 캡처 해상도가 실제 픽셀 수를 따라가도록 수정했습니다. 보조 창도 현재 화면의 Retina 배율로 표시합니다.
- **1.4** — 기본 PiP의 데스크톱·전체 화면 전환, 창 크기와 재생 조작, 공간 전환 중 마지막 프레임 유지, 보호 영상 자동 감지와 캡처 중지·재개를 포함한 첫 공개 소스입니다.
